# 🌿 Dew Monday

> **An idea incubator for the Dew Monday brand ecosystem.**

Dew Monday is a multi-concept creative brand exploring the intersection of gear, art, education, and community for modern creators. This repository serves as the central hub for ideation, documentation, and planning across all brand directions.

---

## 🗂️ Repo Structure

```
dewmonday/
├── concepts/
│   ├── camera-dropshipping/     # Gear & photography product reselling
│   ├── art-dropshipping/        # Print-on-demand & original art reselling
│   ├── art-tutorial-app/        # Educational app for artists & creators
│   └── creator-hub/             # Community & resource platform for creators
├── brand/                       # Brand identity, guidelines, and assets
├── .github/
│   └── ISSUE_TEMPLATE/          # GitHub issue templates

```

## 🎯 Mission

Dew Monday exists to lower the barrier between creative ambition and real output — whether that means getting the right gear into someone's hands, helping an artist learn a new technique, or giving a creator a place to grow alongside their peers.

---

## 🛠️ Contributing & Branching

Each concept lives in its own subdirectory and can be developed independently. Suggested branch naming:

```
concept/camera-dropshipping
concept/art-tutorial-app
feature/brand-identity
spike/market-research
```

Open a GitHub Issue or Discussion before starting significant work on any concept.
